## ✨ Key Features

- 아이템이 삽입된 블록을 터트리면
    - [즉발 아이템 (검정)] - 아이템이 즉발 사용된다
    - [장비 아이템 (노랑)] - 장비창에 아이템이 쌓인다
- 즉발 아이템 : 3x3 Boom | Vertical Boom | Horizontal Boom | +10'sec |
- 장비 아이템 : Clean All Board | x2 Point for 10's | Reload my Block
